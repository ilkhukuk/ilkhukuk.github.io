# İlker Şendoğan | Yazılım Hizmetleri

Web sitesi ve SEO, mobil uygulama ve kurumsal yazılım hizmetleri için hazırlanmış tek sayfalık kişisel site.

## Özellikler

- Saf HTML, CSS ve JavaScript. Derleme adımı ya da bağımlılık yok.
- Telefon, tablet ve masaüstünde çalışan duyarlı tasarım, mobil açılır menü.
- Açık ve koyu tema (cihaz ayarına göre).
- SEO uyumlu yapı: Türkçe içerik, anlamlı başlıklar, meta açıklama, Open Graph etiketleri, schema.org (JSON-LD).
- Kaydırmayla çalışan animasyonlar, container query'ler ve `@property` gibi güncel CSS özellikleri.

## Dosyalar

| Dosya | Açıklama |
| --- | --- |
| `index.html` | Sitenin tamamı (içerik, stil ve betik tek dosyada) |
| `logo.svg` | Logo dosyası |

## Yerelde açma

`index.html` dosyasını tarayıcıda açmanız yeterli.

## Yayınlama (GitHub Pages)

1. Depoda **Settings, Pages** bölümüne gidin.
2. Source olarak **Deploy from a branch**, branch olarak **main** ve klasör olarak **/ (root)** seçin.
3. Birkaç dakika sonra site `https://kullaniciadi.github.io/depoadi` adresinde yayına girer.

## İletişim formu

Form Formspree üzerinden çalışır. Mesajlar Formspree hesabındaki e-posta adresine gelir. Adresi değiştirmek için `index.html` dosyasındaki `FORM_ENDPOINT` satırını düzenleyin.
