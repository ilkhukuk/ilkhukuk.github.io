# ilkhukuk | Yazılım Hizmetleri

Web sitesi ve SEO, mobil uygulama, kurumsal yazılım ve yapay zeka (AI) çözümleri için hazırlanmış tek sayfalık kişisel site.

## Özellikler

- Saf HTML, CSS ve JavaScript. Derleme adımı ya da bağımlılık yok.
- **Modern Tipografi:** Başlıklarda `Space Grotesk`, metinlerde `Inter`, teknik detaylarda `JetBrains Mono` fontları kullanıldı.
- **Gelişmiş Duyarlı Tasarım:** Telefon, tablet ve masaüstünde çalışan esnek (responsive) tasarım.
- **Mobil Alt Navigasyon:** Mobilde ekranın altına sabitlenen; Hizmetler, Çalışmalar, SSS ve WhatsApp hızlı erişim butonları.
- **Açık ve Koyu Tema:** Sistem ayarına duyarlı, kullanıcı isteğine göre hafızada saklanan (localStorage) tema özelliği. (TR, EN, DE dil destekli)
- **Etkileşimli Animasyonlar:**
  - Hero alanında yumuşak sayfa girişi (Fade-Up).
  - Organik ziyaret grafiğinde yavaş ve sıralı çubuk animasyonu.
  - Lighthouse skorlarında sayıların eşzamanlı arttığı halka dolum animasyonu.
  - Butonlarda parlama (Shimmer) efekti ve form alanlarında odak (Focus) ışıması.
- **Sabit Butonlar:**
  - Sol altta yüzen WhatsApp iletişim butonu (mobilde alt menüye taşınır).
  - Sağ altta siteye uygun, çizgisel (mühendislik temalı) "Yukarı Çık" butonu.
- **SEO Uyumlu Yapı:** Türkçe içerik, anlamlı başlıklar, meta açıklama, Open Graph etiketleri, schema.org (JSON-LD) ve genişletilmiş sosyal medya bağlantıları.
- **Güncel CSS Özellikleri:** Kaydırmayla çalışan (scroll-driven) animasyonlar, container query'ler ve `@property` kullanımı.

## Yerelde açma

`index.html` dosyasını tarayıcıda açmanız yeterli.

## Yayınlama (GitHub Pages)

1. Depoda **Settings > Pages** bölümüne gidin.
2. Source olarak **Deploy from a branch**, branch olarak **main** ve klasör olarak **/ (root)** seçin.
3. Birkaç dakika sonra site `https://kullaniciadi.github.io/depoadi` adresinde yayına girer.

## İletişim formu

Form Formspree üzerinden çalışır. Mesajlar Formspree hesabındaki e-posta adresine gelir. Adresi değiştirmek için `index.html` dosyasındaki `FORM_ENDPOINT` satırını düzenleyin.
